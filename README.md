## ¿Qué tienes que hacer?

Sigue el guión de la práctica paso a paso. Integra las propuestas de manipulación de vídeo.

1. **Instala** las dependencias y **arranca** el proyecto:

```bash
npm install
npm run dev
```

2. **Abre** `http://localhost:5173` en el navegador.

3. **Sigue** las actividades del guion.

4. **Haz commit y push** al finalizar cada sesión:

```bash
git add .
git commit -m "P2: [descripción de lo que has implementado]"
git push
```
